# Project Documentation

This folder contains the complete Business Analyst case study for Project 01: UK Banking Complaints Performance & Process Improvement.

The documentation covers the business problem, objectives, methodology, stakeholder analysis, FCA data findings, AS-IS and TO-BE process maps, proposed KPIs, business requirements, requirements traceability matrix, gap analysis, recommendations and conclusion.

The project uses publicly available FCA 2026 H1 firm-level complaints data. Process maps and operational recommendations are illustrative and have not been implemented or validated within a real banking organisation.
