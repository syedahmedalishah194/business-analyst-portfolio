# Process Maps

This folder contains the AS-IS and TO-BE banking complaints-handling process diagrams created using draw.io (diagrams.net).

**AS-IS:** An illustrative complaints-handling workflow used to identify potential process bottlenecks.

**TO-BE:** A proposed improved workflow incorporating complaint information validation, assignment queue monitoring and evidence-request tracking.

Both diagrams form part of an independent Business Analyst portfolio case study. They do not represent verified internal banking procedures or implemented process improvements.
