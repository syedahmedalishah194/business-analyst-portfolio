# Power BI Dashboard

This folder contains the Power BI dashboard for Project 01: UK Banking Complaints Performance & Process Improvement.

The interactive two-page report analyses FCA 2026 H1 banking and credit-card complaints data for 48 selected firms.

**Page 1 — Complaint Overview:** Complaint volumes and unweighted average three-day closure rates across analyst-defined firm categories.

**Page 2 — Complaint Outcomes:** Unweighted average complaint upheld rates and the top five firms by complaints opened.

The report includes interactive firm-category filters. Findings are exploratory and do not establish the causes of complaint-handling delays.
